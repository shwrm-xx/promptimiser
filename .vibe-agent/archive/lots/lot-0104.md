## Décisions (et pourquoi)

- Le bullet ARCHITECTURE du champ `us` (#101) manquait alors que le bullet #102 y renvoyait
  (« même philosophie que le pointeur us, lot #101 ») : renvoi dans le vide, comblé en
  premier — un lecteur suivant la référence ne trouvait rien.
- Décision « Maille User Story : non » réconciliée plutôt que réécrite : le pointeur `us` ne
  rouvre pas la décision (la maille de pilotage reste le lot ; l'US est un document optionnel
  référencé, jamais une ligne du plan ni un niveau de hiérarchie).
- Frontière posée comme décision d'architecture nommée : « pointeur seul, zéro réseau, zéro
  secret ». MCP Atlassian écarté à ce stade AVEC la raison : token API = violation « zéro
  secret », appels réseau dans des hooks fail-open (panne/latence Jira dégraderait des
  sessions locales), dépendance externe. Besoin couvert = traçabilité (commit ⇄ ticket via
  trailer PMZ-Jira, fiche d'archive, export), pas synchronisation. Porte laissée ouverte :
  un MCP configuré côté utilisateur, hors PMZ, les clés PMZ restant le point de jonction.
- README : un seul bullet « Pointeurs US & Jira » dans « Comportement dans Claude Code »
  (champs + commandes + surfaces + frontière) — pas de section dédiée, cohérent avec le
  grain des autres bullets.
